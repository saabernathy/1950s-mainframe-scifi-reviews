# UNIVAC-IV Data Archive: The Speculative Register

> **Model 704-B Digital Repertory System**  
> *Acoustic Delay-Line Retrieval • Vintage Cinematic Records (1950–1957)*

An interactive retro-futuristic web experience styled as a 1950s vacuum-tube electronic mainframe computing system, presenting analytical reviews and telemetry dossiers for landmark 1950s science fiction cinema.

---

## 📽️ Archival Records Included

1. **Destination Moon (1950)** – Dir. Irving Pichel & Robert A. Heinlein
2. **The Day the Earth Stood Still (1951)** – Dir. Robert Wise
3. **The War of the Worlds (1953)** – Dir. Byron Haskin
4. **Them! (1954)** – Dir. Gordon Douglas
5. **Forbidden Planet (1956)** – Dir. Fred M. Wilcox
6. **The Incredible Shrinking Man (1957)** – Dir. Jack Arnold

---

## ⚡ Mainframe Interface Features

- **Operator Annunciator Console**: Illuminated jewel status indicators, dual spinning magnetic tape reels, and binary switch register.
- **Punch Card Separators**: IBM/UNIVAC punch card visual partitions.
- **Oscilloscope Bellows & Bezel Displays**: Circular oscilloscope CRT viewport aesthetics with animated green scanlines.
- **Teleprinter & Teletype Dossiers**: Monospaced typography with authentic mainframe readouts, technical parameters, and logic verdict lamps.
- **Pure Web Technologies**: Vanilla HTML5 and CSS3 (CSS Grid, Flexbox, Keyframe Animations, Google Fonts: *Chivo Mono* & *Share Tech Mono*).

